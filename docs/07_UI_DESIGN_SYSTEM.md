## Design System Tokens & Aesthetics

- **Theme Palette**: Modern dark mode cyber-defense theme (`#0a0f1d` root background, `#111827` panel background).
- **Accent Colors**: Cyber Cyan (`#00f0ff`), Alarm Red (`#ff0055`), Warning Amber (`#f59e0b`), Success Emerald (`#10b981`).
- **Typography**: Clean sans-serif system fonts with monospace badges for IPs, hashes, ports, and MITRE ATT&CK codes.
- **Glassmorphism**: Subtle panel borders (`1px solid rgba(0, 240, 255, 0.15)`) and backdrop blur effects.
- **Viewport Lock**: Single-shell dashboard container preventing horizontal scrolling under 100% browser zoom.
